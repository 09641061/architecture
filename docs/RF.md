# Requisitos funcionales

Enfoque de spa

## Sistema de agenda

* El sistema debe poder agendar citas en un calendario con la infomracion de servicio (incluir ejemplos, hora, duracion, precio, descripcion)

* El sitema debe poder modificar los servicios que ofrece (nombre, precio, productos a usar, tiempo estimado de duracion).

* El sistema debe poder mostrar las citas en un calendario.

## Envio de notificaciones

* El sistema debe poder enviar notificaciones a los clientes para recordarles sus citas. (notificaciones push, whatsapp)

* El sistema debe poder enviar notificaciones a los empleados para recordarles sus citas. (notificaciones push, whatsapp)

## Analiticas y reportes

* EL sistema debe mostrar meditricas de cantidad re reservas, dinero acumulado de reservas por mes, semana, dia.

## Roles y permisos

* El sistema debe poder modificar los roles de editar o leer la agenda.

* El sistema debe editar el rol para leer las analiticas.

* El sistema debe poder registrar a al empleado con sus roles

* El sistema debe poder mostrar la informacion basica de los empleados y sus roles y permisos.

* El sistema debe poder restringir las funciones de la aplicacion segun el rol del usuario.


## Agente IA
* El sistema debe conectarce a telegram o whatsapp.

* El sistema debe tener un agente de ia que haga peticiones https al servicio de agenda y pueda obtener los horarios disponibles y confirmar o cancelar citas.

* El sistema debe usar al agente para realiza resúmenes y predicciones de las ganancias, servicios mas reservados, producto mas usado por dia, semana, mes.

* El sistema debe permitir al usuario configurar el agente para enviar las notificaciones en los horarios que desee.
